THE VERIFICATION MODEL

Meaning meets math.

1. Commit the source

Register up to 100 period/category rows in integer base units, with metric, scope, unit, and provenance. SHA-256 binds the exact UTF-8 bytes. Optional GitHub source URLs must use a full immutable commit.

2. Lock the claim

The prose, reported value, exact operation, period, baseline, category, and declared chart are immutable. Growth requires identical category cohorts. Percentage outputs use percentage points; input supports three decimal places.

3. Independently assess

GenLayer validators retrieve any linked source independently. AI checks metric meaning and framing; exact integer fractions check the value. Validators must agree on all decision-critical fields. The contract recomputes arithmetic before writing a receipt.

4. Keep a bound receipt

Each receipt contains the dataset hash, claim ID, calculation, meaning/framing states, and previous receipt hash. Only the submitter can review; at most three attempts are allowed, and conclusive verdicts cannot be overwritten.

Deterministic verdict rules

VerdictRule, in order
INCONCLUSIVEUnverifiable source, undefined math, invalid AI response, or unknown meaning/framing.
INCORRECTReported number differs from the exact fraction by more than half a thousandth.
MISLEADINGNumber matches but meaning, framing, truncated/clipped bars, or chart unit is misleading.
ACCURATEAll numerical, semantic, and declared-chart checks pass.

Bar charts describe individual row values, not totals. This version does not inspect image pixels, arbitrary chart scripts, spreadsheets, or PDFs. Publisher provenance is an assertion. AI assessments can be wrong; consensus is not a guarantee of truth. Public Studionet is a development network and may reset.
